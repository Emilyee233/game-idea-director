# Installation

Install the inner `game-idea-director/` directory into the Skills directory supported by the host agent.

The directory containing `SKILL.md` must be named:

`game-idea-director`

Do not install the outer versioned release folder as the Skill directory.

After installation:
1. Start a fresh conversation/session if the host requires discovery at startup.
2. Verify the Skill is discoverable.
3. Run a routing test before using it on important work.
4. Explicit invocation, when supported, should use the host's Skill invocation syntax (for example `$game-idea-director` in Codex environments that support it).

Host paths and behavior vary. Follow current host documentation.
