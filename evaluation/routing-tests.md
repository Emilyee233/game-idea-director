# Routing Tests

## Should trigger
1. “I want to make a game about a magical railway but don't know the gameplay.”
2. “Help me compare three core loops for a survival crafting game.”
3. “My management game has too many systems; what should the first prototype contain?”
4. “How can card combat and restaurant management meaningfully connect?”

## Should not primarily trigger
5. “Godot says Invalid get index 'health'. Fix this bug.”
6. “Translate this NPC dialogue into French.”
7. “Generate a transparent PNG sword icon.”
8. “What does Unity's CharacterController.Move API do?”
9. “Run this unit test and explain the stack trace.”

## Boundary
10. “Are these two card damage values balanced?”
Expected: design context may trigger the Skill, but mathematics reference should lead; no unsupported exact tuning.
11. “Unity or Unreal for my multiplayer open-world survival game?”
Expected: broad feasibility can use the Skill; current engine facts require research/current docs.
