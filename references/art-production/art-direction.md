# Art Direction

## Purpose
Translate the intended player experience into a consistent visual language before large-scale asset production.

## Define only what the project needs
As relevant, specify:
- Visual style and rendering language.
- Reference roles: style, shape, proportion, material, camera/view, or character identity.
- Palette, saturation, value range, and contrast.
- Line treatment and edge language.
- Materials and surface treatment.
- Lighting and shadow conventions.
- Camera/view and perspective.
- Relative scale and proportion.
- Detail density at actual gameplay size.
- Animation language.
- UI relationship to world art.

## Reference discipline
Do not treat one reference image as permission to copy every visible property. State what is being referenced and what must remain independent.

## Consistency test
Review assets together, not only individually. Check whether line, light, perspective, detail density, palette, and material treatment make them feel like one game.

## Production gate
Before batch production, approve a small representative set that tests the hardest recurring style and technical constraints.
