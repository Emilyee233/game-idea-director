# Action & Combat Design

Use when timing-sensitive combat, movement, attacks, defense, evasion, aiming, or execution mastery is central.

## Design dimensions
- Intended combat fantasy: power, precision, desperation, tactics, expression, vulnerability, or another goal.
- Core verbs: move, aim, attack, block, parry, evade, reposition, use abilities.
- Decision pressure: timing, spacing, target priority, resource commitment, risk versus safety.
- Execution: responsiveness, animation commitment, buffering/cancelling where appropriate.
- Readability: telegraphs, hit confirmation, danger and state clarity.
- Opponents: distinct behavioral problems, not only different statistics.
- Resources: health, stamina, ammunition, cooldowns, charges, position, time.

## Common failures
- Attacks differ mainly by damage.
- Enemies are health pools without distinct pressure.
- Defensive actions have no trade-off.
- Difficulty is mostly larger numbers.
- Effects obscure important information.

## Prototype
Test one player kit against a very small enemy set. Validate movement, timing, commitment, defense, readability, and feedback before producing many weapons, enemies, or abilities. Do not claim good game feel from text alone.
