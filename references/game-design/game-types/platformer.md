# Platformer Design

Use when movement, jumping, traversal, timing, spatial control, or obstacle navigation is central.

## Design dimensions
Acceleration, speed, jump arc, air control, landing, input forgiveness where appropriate, camera, collision readability, movement rhythm, mechanic introduction, checkpoints and failure cost.

## Common failures
Physics fight player intent; hidden information causes failure; camera creates failures unrelated to skill; precision exceeds input/readability; mechanics appear without safe learning space.

## Prototype
Tune one movement kit in a graybox course before producing many levels. Movement feel and camera behavior must be tested in-engine.
