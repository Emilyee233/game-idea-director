# Roguelike & Roguelite Design

Use when runs, resets, procedural variation, repeated mastery, randomized rewards, or run-to-run change are central. Permanent progression and procedural maps are not mandatory.

## Design dimensions
Moment decisions; run decisions; between-run change if present; what varies; what remains learnable; how randomness creates adaptation; build opportunities; recovery from weak rewards; reset motivation.

## Common failures
Randomness decides viability before meaningful choices; meta upgrades become grinding; runs are long before builds become interesting; content variety masks shallow decisions; a few combinations dominate.

## Prototype
Build a short run with limited content but enough variation to test adaptation, build direction, risk/reward, and reset motivation.
