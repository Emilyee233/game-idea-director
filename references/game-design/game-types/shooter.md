# Shooter Design

Use when aiming, firing, weapon handling, target prioritization, movement under threat, or projectile interaction is central.

## Design dimensions
Aim/input; weapon identity; range/cadence/accuracy/recoil/reload/ammunition/mobility; target behavior; positioning; time-to-kill; hit feedback; resource pressure.

## Common failures
Weapons differ mainly by damage; enemies are targets rather than combat problems; effects obscure aim/threats; time-to-kill removes decision space or creates purposeless sponginess.

## Prototype
Use a tiny weapon and enemy set to test aim, movement, target priority, weapon roles, and feedback.
