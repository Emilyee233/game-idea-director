# Tower Defense Design

Use when players deploy defenses against predictable or partially predictable enemy flows.

## Design dimensions
Pathing/topology; enemy roles; tower roles/coverage/targeting; economy timing; future-threat information; placement constraints; recovery from mistakes.

## Common failures
One tower dominates; waves differ only by health; optimal placements are static; economy snowballs irreversibly; upgrades always dominate new placement or vice versa.

## Prototype
Use one compact map, a few enemy roles, and a few genuinely different defenses. Test whether placement and investment decisions change with wave composition.
