# Game Balance Framework

Balance is contextual. A value is meaningful relative to intended experience, alternatives, opportunity costs, encounter context, resources, player information, progression, synergies, and edge cases.

## Three layers
1. Analytical: formulas, rates, efficiency, thresholds.
2. Systemic: interactions, strategies, loops, dominant options.
3. Experiential: fairness, clarity, challenge, variety, satisfaction.

Passing one layer does not prove the others.

## Baselines
Use value per resource/time/action, breakpoints, expected value, marginal value, opportunity cost, variance, and reliability as comparison tools—not automatic verdicts. State assumptions.

## Exact-number rule
Do not recommend a precise tuning value merely because it lies between existing values. Exact tuning needs a target, formula, breakpoint, simulation, or explicit test hypothesis. If evidence supports only a range, give a range.

## Workflow
Define role and experience → identify variables/constraints → choose baselines → find thresholds/edge cases → generate plausible range → simulate when needed → playtest → retune and rerun affected tests.

Never label a design balanced solely from theory.
