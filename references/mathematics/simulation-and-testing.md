# Numerical Simulation & Testing

Use simulation when random variables interact, state evolves over time, feedback loops exist, deck consistency depends on many rules, economy outcomes depend on choices, or many builds/encounters interact.

## Workflow
Define question → assumptions/rules → inputs/distributions → outputs/metrics → validate simple cases → run sufficient trials → inspect distributions/edge cases → compare with gameplay data when available.

Possible metrics include win rate, turns/actions, resource balance, failure probability, draw consistency, option pick rate, output distribution, overkill/waste, progression time, and dead-end rate.

Simulation tests behavior under its assumptions. It cannot prove fun, fairness perception, clarity, or motivation.
