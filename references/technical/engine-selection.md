# Engine Selection

## Purpose
Choose an engine based on project requirements and team constraints rather than popularity or generic rankings.

## Compare
- Target platforms.
- 2D/3D requirements.
- Rendering and animation needs.
- Networking needs.
- Tooling and editor workflow.
- Programming language/ecosystem.
- Asset pipeline.
- Performance requirements.
- Team familiarity.
- Licensing/business constraints.
- Deployment and maintenance.

## Evidence
Engine capabilities and licensing can change. Verify current official documentation for version-sensitive claims.

## Decision
Separate:
- Hard requirements.
- Strong preferences.
- Nice-to-have features.
- Migration cost.

Do not recommend switching engines merely because another engine is theoretically stronger. Existing project investment and team competence matter.
