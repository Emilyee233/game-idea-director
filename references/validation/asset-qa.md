# Asset QA

## Purpose
Review game assets at visual, technical-file, and in-engine levels.

## Visual QA
Style, proportion, silhouette, color, material, completeness, readability.

## Technical asset QA
Dimensions, format, alpha, layers, naming, frames, pivots, masks, file integrity.

## Integration QA
Scale, anchor, occlusion, collision, animation, UI behavior, references, runtime readability.

Track these separately. A visually approved image may still fail integration.
