# Functional Testing

## Purpose
Verify that implemented behavior matches confirmed rules.

## Test categories
- Normal path.
- Boundary values.
- Invalid input.
- State transitions.
- Repeated/reentrant actions.
- Save/load or reset where relevant.
- Failure/recovery.
- Regression of affected behavior.

## Test case
Record:
- Objective.
- Preconditions.
- Steps.
- Expected result.
- Actual result.
- Evidence.
- Status.
- Severity.
- Follow-up.

Never mark Passed without actual execution evidence.
