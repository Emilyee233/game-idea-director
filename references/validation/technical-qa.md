# Technical QA

## Purpose
Verify runtime stability and platform behavior separately from game-design quality.

## Areas
- Startup/shutdown.
- Crashes/errors.
- Save/load integrity.
- Performance and memory.
- Resolution/input/device behavior.
- Platform compatibility.
- Networking where applicable.
- Missing/corrupt assets.
- Recovery from failure.

Use target hardware/platform evidence when platform performance matters. A developer machine is not sufficient evidence for all targets.
